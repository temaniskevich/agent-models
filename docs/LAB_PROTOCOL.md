# Протокол «лаборатории» для банковского канала — ЧЕРНОВИК

**Статус: черновик от 18.11.2026, не зафиксирован.** Числовые пороги и состав методов обсуждаются с автором. Протокол фиксируется коммитом
**после** входных проверок (раздел 9) и **до** реализации оценщиков и любого запуска на реальных данных. Всё, что изменено после фиксации, помечается как отклонение.

## 1. Вопрос

Правильно ли стандартные и современные методы восстанавливают **неоднородный** эффект ключевой ставки на кредитование банков — прежде всего **направление**
неоднородности («банки с меньшим запасом капитала реагируют сильнее»), когда (а) ограничение по капиталу то связывает банки, то нет, и (б) политика эндогенна?
Какие из методов можно применять к российским данным по отдельным банкам?

Почему агентная модель: в ней известна причинная истина для **каждого банка** — эффект измеряется парными прогонами с общими случайными числами
(раздел 3). Реальные данные этого не дают, DSGE с репрезентативным банком не даёт неоднородности.

Связь с литературой (проверить перед подачей): David, Giacomini, Jiao, Wang (arXiv 2605.05404) — линейные LP с взаимодействием восстанавливают лишь проекцию
функции отклика, идентификация требует линейности условного среднего по шоку; Ablay, Xu, Wang (arXiv 2611.00677) — panel LP против panel VAR; Kolesár, Plagborg-Møller (2024) —
LP в нелинейном мире; Li, Plagborg-Møller, Wolf (J. Econometrics, 2024) — сравнение методов на тысячах **линейных** DGP; Advani, Kitagawa, Słoczyński (JAE, 2019) —
ограничения выбора метода по симуляциям; Athey, Imbens, Metzger, Munro (J. Econometrics) — DGP для Монте-Карло из генеративных моделей.
Россия: Juurikkala, Karas, Solanko (2011); Тишин (RJMF, 2019) — высокочастотные сюрпризы ДКП.

## 2. Оцениваемые величины (истина)

Банк i, месяц шока t0, горизонт h ∈ {3, 6, 12}, шок δ = +1 п.п. ключевой ставки.
- **Эффект банка:** `τ_{i,h}(t0) = E[ 100·ln L_{i,t0+h}(δ) − 100·ln L_{i,t0+h}(0) | состояние сектора в t0 ]` — % кредитов на 1 п.п.; отдельно для кредитов организациям,
  населению и суммарных.
- **Состояние банка** до шока `x_i` (месяц t0 − 1): запас капитала `CAR − CAR_target` (главное), ликвидность (ликвидные активы / вклады), размер (ln активов).
- **Средний эффект** ATE_h: равновзвешенный и взвешенный по активам.
- **Неоднородность (главная величина):** `Δτ_h = τ̄(нижняя треть по запасу капитала) − τ̄(верхняя треть)`; дополнительно — ранговая корреляция τ и запаса капитала.
  В регрессиях с временными эффектами идентифицируются только **относительные** эффекты — им соответствует Δτ; уровень сравнивается с ATE только у методов без временных эффектов.

## 3. Как считается истина (проверено 18.11.2026)

Одна пара прогонов с одним зерном не годится: дискретные события (выбор партнёров на МБК, выбытие, вход банков) усиливают малые различия, и отклик отдельного банка на
крошечный сдвиг ставки (0,01 п.п.) получается хаотичным (от −27 % до +8 % в пересчёте на 1 п.п.). Поэтому:
- **Разветвление.** Модель доводится до t0, её состояние копируется; для r = 1…R продолжения «с шоком» и «без шока» получают **одинаковые** новые зёрна всех шести потоков
  случайных чисел; `τ̂_{i,h}(t0)` — среднее разностей по r.
- Проверка (300 банков, R = 20, параметры по умолчанию): стандартная ошибка истины по банку ≈ 0,04 п.п. при разбросе эффектов между банками p5–p95 = −1,6…+3,5;
  у 98 % банков |τ̂| > 2·SE; 40 продолжений — 4 с. **Правило:** R подбирается так, чтобы медианная SE истины была ≤ 10 % межбанковского стандартного отклонения τ.
- Банк, выбывший в одном из продолжений, исключается из истины на этом горизонте (доля таких сообщается).
- **Наблюдение:** в параметрах по умолчанию средний эффект **положителен** (+0,8 %/п.п.) — известный режим ограниченного предложения (`IRF_RESULTS.md`).
  Это проверка реалистичности, а не результат (раздел 9, G3).

## 4. Семейство DGP (лаборатория)

**Доработки модели (до фиксации протокола):**
1. **Правило политики.** Новый вид сценария: `k_t = ρ·k_{t−1} + (1 − ρ)·(k* + φ_π·π_t + φ_c·разрыв_кредита_t) + ε_t`; π_t — сокращённый блок инфляции
   (AR(1) со своими шоками и откликом на кредит). При φ > 0 изменения ставки эндогенны; ε_t — «истинный» шок политики.
2. **Наблюдаемый шок с ошибкой:** `s_t = ε_t + η_t`, var(η)/var(ε) = κ (аналог высокочастотного сюрприза).
3. **Сектор:** N банков с реалистичным распределением размеров (доля крупнейшего ≈ 1/3, хвост — малые банки).
4. Разветвление и сбор истины (раздел 3) — отдельный модуль, без изменения бухгалтерии; тождества проверяются и в продолжениях.

**Факторы плана** (латинский гиперкуб, ≈ 200 точек; в каждой точке — одна «наблюдаемая» история и истина в 6 датах t0):

| Фактор | Значения | Зачем |
|---|---|---|
| Доля банков, упирающихся в ограничение по капиталу | 0 (не связывает) … 40 % | главный фактор нелинейности |
| Режим кредита | ограничен спросом / предложением (`demand.backlog_exit`, тренды) | известная структурная неопределённость модели |
| Эндогенность политики φ | 0; умеренная; сильная | смещение LP по Δk |
| Шум наблюдаемого шока κ | 0; 0,5; 1 | слабый инструмент |
| Длина панели T | 72; 144 мес. | 144 ≈ 2014–2025 |
| Число банков N | 100; 300 | порядок реального сектора |

**Сравнительные DGP (для вопроса «можно ли выбирать метод по синтетике»):**
- **D-ABM** — агентная модель (основной);
- **D-lin** — линейный панельный двойник: панельный VARX по банкам, подогнанный к D-ABM (аналог двойника из `CAPACITY_PROTOCOL.md`, раздел 12), истина — его аналитические отклики;
- **D-nobind** — агентная модель с несвязывающим ограничением по капиталу (почти линейный случай).

## 5. Что видят методы

Помесячная панель банков (кредиты по сегментам, вклады, капитал, CAR, ликвидность, активы) за T месяцев, ключевая ставка и наблюдаемый шок s_t. Без истины,
без ε_t и без параметров DGP. По желанию — слой наблюдения (шум отчётности 1–2 %), фиксируется до запуска.

## 6. Методы (фиксированный список; гиперпараметры задаются до запуска)

| Код | Метод | Что оценивает |
|---|---|---|
| E1 | агрегатная LP по Δk_t (МНК) | ATE (смещение из-за эндогенности) |
| E2 | агрегатная LP-IV по s_t | ATE |
| E3 | panel LP: `Δ_h ln L_{i,t+h} = α_i + γ_t + β_h·(Δk_t × x_{i,t−1}) + контроли` | Δτ (относительный) |
| E4 | то же с s_t вместо Δk_t (или IV) | Δτ |
| E5 | непараметрическая state-dependent panel LP (сито по x; David et al.) | τ(x), Δτ |
| E6 | panel VAR с взаимодействиями (Ablay et al.) | τ(x), Δτ |
| E7 | DML с неоднородностью по x (частично линейная модель, лес для nuisance) | Δτ |
| E8 | causal forest с непрерывным «лечением» s_t (GRF) | τ(x), Δτ |

Интервалы: Дрисколл–Края / кластеризация по времени для E3–E4 (шок общий для всех банков — эффективный размер выборки ≈ T, а не N·T); для E7–E8 — штатные.

## 7. Метрики и гипотезы (пороги — ПРЕДЛАГАЕМЫЕ)

Для каждой точки плана и метода: смещение и RMSE для ATE и Δτ; покрытие 90 % интервала; **ошибка знака неоднородности** — интервал для Δτ не содержит 0,
а знак противоположен истине; **пропуск** — истинное |Δτ| ≥ 0,5 %/п.п., а интервал содержит 0. Плацебо: точки с истинным Δτ ≈ 0 — частота ложной неоднородности.

- **L1 (линейный эталон).** В D-lin и D-nobind метод E3/E4 даёт ошибку знака ≤ 5 % и покрытие ≥ 80 %. Если нет — лаборатория или реализация неисправна, дальше не идём.
- **L2 (главная).** В D-ABM при доле связывающих банков ≥ 10 % метод E3/E4 **вводит в заблуждение**: ошибка знака ≥ 10 % **или** покрытие < 70 %.
  Опровергается, если ошибка знака ≤ 5 % и покрытие ≥ 80 %; иначе — «не определена».
- **L3.** E5 (непараметрическая) снижает ошибку знака относительно E4 не менее чем вдвое в тех же точках.
- **L4 (эндогенность).** При φ > 0 |смещение| E1 ≥ 30 % истинного ATE; у E2 при κ ≤ 0,5 — ≤ 10 %.
- **L5 (перенос выбора метода).** Ранжирование методов по RMSE Δτ в D-ABM и D-lin совпадает (τ Кендалла ≥ 0,6) — выбор метода по простой синтетике надёжен;
  τ < 0,3 — ненадёжен (выбор зависит от DGP, рекомендация — сообщать все методы, как у Advani et al.).
- Результаты по факторам плана (где методы ломаются: доля связывающих, T, κ) — описательно, метамодель «ошибка знака ~ факторы».

## 8. Применение к России

- **Данные:** форма 101 по банкам (помесячно), 2014–2025; кредиты организациям и населению в рублях; запас капитала — по форме 135 (Н1), если опубликована,
  иначе приближение «капитал / активы» по 101; сопоставление ведётся в тех же определениях, что в лаборатории.
- **Шоки:** высокочастотные сюрпризы ДКП (Тишин; RJMF 2024) — на месяцы, где они есть; эпизоды 2014–15, 2022, 2023–24.
- **Правило:** на реальных данных оцениваются **все** методы E1–E8; основным выводом считается метод, прошедший лабораторию в точках плана, близких к российским
  (по входным моментам, раздел 9), остальные — проверка устойчивости. Расхождение методов публикуется.
- Сравнение с прежними оценками по РФ (слабокапитализированные банки реагируют сильнее — Juurikkala et al.) — прямо проверяемо.

## 9. Входные проверки (до фиксации протокола)

- **G1 — данные по банкам.** Наличие формы 101 (и 135) помесячно за 2014–2025; число банков по годам; пропуски после 2022 г. (ЦБ ограничивал публикацию отчётности).
  Если для 2022–2023 данных нет — окно применения сокращается, и это записывается до запуска.
- **G2 — шоки.** Ряд российских сюрпризов ДКП, покрывающий ≥ 2014–2024; иначе — запасной вариант (остатки оценённого правила политики) с явной пометкой «слабая идентификация».
- **G3 — реалистичность DGP.** Агентная модель в части точек плана должна воспроизводить по данным 101: знак среднего отклика кредитов на рост ставки (сейчас по умолчанию
  неверен: +0,8 %), разброс роста кредитов между банками, распределение размеров и CAR, долю банков у минимума капитала. Точки, где это не выполняется, остаются
  в лаборатории (это «другие миры»), но в выбор метода для России (раздел 8) идут только реалистичные. Критерии реалистичности задаются числами до запуска.
- **G4 — точность истины.** Медианная SE истины ≤ 10 % межбанковского разброса τ (раздел 3) во всех точках; иначе увеличивается R.

## 10. Порядок работ и запреты

1. Доработки модели (раздел 4) с тестами тождеств и детерминизма; модуль истины с разветвлением.
2. Входные проверки G1–G4; фиксация протокола коммитом.
3. Отладка оценщиков — только на D-lin (истина аналитическая) и на 5 отладочных точках D-ABM, не входящих в план.
4. Один основной запуск по плану; публикация при любом исходе. Затем — применение к данным 101.
Нельзя после основного запуска: менять пороги, методы, гиперпараметры, факторы и точки плана; настраивать что-либо по реальным данным.

## 11. Известные ограничения

- Истина верна только внутри модели. Защита: сравнение с D-lin и D-nobind (L5) и отбор реалистичных точек (G3) — но не доказательство переноса на реальность.
- Агентная модель ошибается в реакции объёмов на ставку (`IRF_RESULTS.md`); здесь это фактор плана (режим кредита), а не цель.
- Если калибровать DGP по тем же данным 101, к которым потом применяются методы, выбор метода частично использует данные дважды (ср. Advani et al.); это указывается.
- Агрегатный шок один на месяц: эффективный размер выборки определяется T (≈ 144), а не числом банков.
