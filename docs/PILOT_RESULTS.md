# Результаты пилота шага 5 (16.11.2026)

Протокол: `docs/PILOT_PROTOCOL.md`. Запуск: `python scripts/run_pilot.py --jobs 6` (300 историй по 120 мес., зёрна 12345; таблицы — в `outputs/pilot/`).
Пилот предварительный: окна 12 и 24 месяца, калибровка с малым бюджетом, простой ARX-прогноз. **Это гипотеза, не вывод для статьи.**

## Сводка (w = 0,5; отношение RMSE к `real`, среднее геометрическое по ячейкам; < 1 — лучше)

| Вариант | Окно B (2022) | Окно A (2014–15, только объёмы) |
|---|---|---|
| `naive` | 0,97 | 0,66 |
| `real` (только реальные данные) | 1,00 | 1,00 |
| `real_shrunk` (сильное сжатие, без синтетики)* | **0,77** | 0,66 |
| `control` (синтетика без экономики) | **0,77** | **0,52** |
| `abm` (агентная модель) | 0,82 | 0,59 |
| `abm` против `control` (отношение RMSE) | 1,06 (хуже) | 1,12 (хуже) |

\* добавлено после пробного запуска (см. протокол).

## Что видно
1. **Формально по заранее заданному правилу** синтетика агентной модели «помогает» относительно `real` в обоих окнах и при всех долях смеси.
2. **Но этот выигрыш не принадлежит экономике модели.** Контроль «без экономики» помогает не меньше, а нейтральное сжатие коэффициентов (без всякой синтетики) даёт
   в окне B тот же результат (0,77). В окне A агентная модель лучше `real_shrunk` лишь на уровне шума.
3. **Агентная синтетика хуже контроля** в обоих окнах (ставки по кредитам населения и рост розничных кредитов — заметнее всего). В окне B при h = 3 она значимо хуже сжатого базиса
   (ДМ, p = 0,001, в неблагоприятную сторону). Остальные различия агентной модели и контроля незначимы (p > 0,1 при 12–24 месяцах).
4. Для ставок наивный прогноз «без изменений» не хуже любой модели; для роста объёмов основной выигрыш — от подавления шума, а не от знания реакции на скачок.
5. Прямая причина слабости реальной выборки: до 2014 г. ключевая ставка почти не менялась, так что реакцию на скачок по реальным данным оценить нечем — именно этот пробел синтетика
   должна была закрыть. Пилот показывает, что синтетика закрывает его не лучше, чем простая регуляризация.

## Что это значит для приоритетов
- Пока нет оснований утверждать, что структура агентной модели полезна для прогноза. Пилот нужно перепроверить после п. 3–5 дорожной карты, прежде всего после сравнения
  реакции модели и данных на скачок ставки (п. 3 в `CLAUDE.md`): если реакция модели расходится с реальной, синтетика не может научить прогнозную модель реакции на скачок.
- Ограничения пилота: 12 и 24 месяца тестового окна (мало мощности), только точечный прогноз и ARX, долг перед ЦБ не прогнозировался, параметры калибровки предварительные,
  дополнения протокола (`real_shrunk`, сравнение с контролем) определены после пробного запуска.
