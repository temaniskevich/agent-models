## Что видно
1. **Ставки банков: форма и скорость реакции воспроизводятся**, кроме ставки по кредитам населения: модель переносит ключевую ставку почти один к одному (≈ 0,9–1,0), данные дают ≈ 0,5.
2. **Объёмы кредитов: реакция неверна по обоим сегментам, в разные стороны.**
   - Кредиты организаций: модель сжимает их на 1,8 % за год на каждый п.п. ставки, в данных реакция около нуля (возвращаются к исходному уровню).
   - Кредиты населения: в данных −1,9 %, в модели в историческом прогоне −0,4 %, а в чистом эксперименте со ступенью +2 п.п. реакция **положительна** (+2,3 % на п.п.).
3. **Диагностика положительной реакции розницы.** Гипотеза: рост ставки сжимает кредит организациям, освобождает капитал, и банки наращивают розницу. Проверка: при ослабленном ограничении
   по капиталу реакция падает с +2,3 до +1,2 %, то есть **объясняет примерно половину**, остальное не выяснено (кандидаты: распределение спроса между банками, рост процентного дохода и капитала).
4. **Вклады**: данные малоинформативны (широкие интервалы), поэтому проверка слабая; модель не противоречит данным в населении и расходится в организациях только на части горизонтов.
5. Предостережение из протокола остаётся: в данных изменения ставки эндогенны и есть шоки, которых нет в модели (валюта, санкции), поэтому расхождение — сигнал, а не доказательство ошибки.

## Что это значит
- Для **прогноза ставок** реакция модели в целом реалистична; для **прогноза объёмов кредита** синтетика сейчас учит неверной реакции. Это согласуется с пилотом шага 5, где агентная синтетика
  не превзошла контроль, особенно по розничным кредитам.
- Доработки модели (по важности): (а) перенос в ставку по кредитам населения (≈ 1 → ≈ 0,5); (б) кредит организациям — слишком сильная и устойчивая реакция на ставку; (в) знак и размер реакции розничных кредитов (канал замещения через капитал);
  (г) слой наблюдения для объёмов. После правок нужно **повторить этот протокол без изменения критериев** и затем пилот шага 5.
- Правки не подгонять под пороги: менять структуру по содержательным причинам, а критерий проверять один раз на итоговой версии; промежуточные прогоны указывать как итерации.

Протокол итераций — в конце `docs/IRF_PROTOCOL.md`. Критерии те же; проверка — на отложенной выборке 2020-01…2026-09, не участвовавшей в калибровке.

## Находки
1. **Данные искажали реакции объёмов.** Ряды суммировали рубли и валюту; девальвация 2014–15 делала «реакцию на повышение ставки» положительной (кредиты организаций, h = 12, 2014–2019: +3,3 % с валютой и +0,3 % только в рублях;
   вклады населения +1,6 → −0,5; вклады организаций +5,4 → +2,1). Загрузчик теперь по умолчанию берёт рублёвые ряды (`load_cbr_monthly(currency="rub")`, суммарные — в `*_all`). Все предыдущие результаты (калибровка A/B, пилот, итерация 1) получены на суммарных рядах.
2. **Ставки банков теперь воспроизводятся**, включая розничный кредит: перенос в модели 0,96 (было ≈ 1), на отложенной выборке реакции по ставкам проходят (кроме ставки по кредитам населения: 0,67 против 0,40 ± 0,23, внутри интервала 17 % горизонтов).
3. **Объёмы кредитов — структурная проблема, не параметрическая.** С параметрами итерации 3 реакция кредитов организаций к 12-му месяцу положительна (+1,2 % на п.п., симметрично для повышения и снижения ставки), в данных ≈ −0,1; розничных — слабая отрицательная вместо −1,2.
   Механизм (проверено экспериментами на модели): модель постоянно находится в режиме **ограничения предложения**. Запас кредитов стоит ≈ на 20 % ниже тренда спроса, выдаётся ≈ 22 % желаемого объёма, недовыполненный спрос ≈ 1,8–2,3 трлн руб. Это не снимается ни ослаблением ограничения по капиталу,
   ни отключением урезания по ликвидности: при ослаблении ограничений банки просто быстрее упираются в то же ограничение. Калибровка компенсирует нехватку предложения завышением трендов спроса (розничный — 0,28, у границы). В таком режиме падение спроса после повышения ставки не сжимает кредит, а лишь перераспределяет ограниченный капитал между сегментами
   (сегмент с более высокой эластичностью теряет, другой выигрывает).
4. Гипотеза «замещение через капитал» из итерации 1 объясняла лишь часть эффекта; полная картина — п. 3.

## Следствия
- Для **ставок** реакция модели реалистична. Для **объёмов** синтетика сейчас учит неверной реакции — прогноз объёмов на синтетике агентной модели использовать нельзя (согласуется с пилотом).
- Следующая доработка структуры (не параметров): согласовать рост предложения кредита с реальным (темп накопления капитала, привлечение капитала, плотность активов, взвешенных по риску) так, чтобы базовый режим был **ограничен спросом**, а не предложением;
  затем перекалибровать тренды и повторить протокол (итерация 4) на отложенной выборке.
