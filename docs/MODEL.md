# Спецификация модели

Документ описывает то, что **реально делает код** (`abm_banks/model.py`). Он — основа раздела «Модель» статьи.
Обозначения: `k` — ключевая ставка, `i` — банк, `s ∈ {орг., нас.}` — сегмент, `L` — кредиты, `D` — вклады,
`K` — капитал, `CAR = K / RWA`. Шаг — месяц, деньги — млрд руб., ставки — годовые доли.

## 1. Агенты и состояние

| Агент | Что хранит | Как действует |
|---|---|---|
| **Банк** `i` (N штук, неоднороден) | баланс: `L_{i,c}, L_{i,r}`, ценные бумаги `sec`, свободная ликвидность `liq`, обязательные резервы `res = ρ·D`, МБК выданный `Σ_j M_ij`, депозит в ЦБ; вклады `D_{i,c}, D_{i,r}`, МБК полученный `Σ_j M_ji`, долг перед ЦБ, капитал `K`; ставки (предлагаемые и «когортные»), стресс `stress_i ∈ [0,1]`, надёжность `trust_i ∈ [0,1]` | ставит ставки, выдаёт кредиты в пределах капитала, управляет ликвидностью (МБК → ЦБ → продажа бумаг; избыток → бумаги/депозит в ЦБ), платит налоги и дивиденды |
| **Клиенты** (вкладчики, заёмщики) | агрегаты: тренд и «желаемые» запасы кредитов/вкладов | выбирают банк по ставке, размеру и надёжности (логит), реагируют на ставки объёмом спроса, бегут из слабых банков при панике |
| **Банк России** | путь `k_t` (вход сценария), коридор ставок, норматив резервирования, залоговая база | рефинансирует под залог по `k + refi_spread`, принимает депозиты по `k − deposit_spread`, отзывает лицензии, докапитализирует системно значимые банки |
| **АСВ / ликвидатор** | страховое покрытие вкладов, возмещение по кредитам | выплачивает вкладчикам и кредиторам при выбытии банка, несёт чистые потери |

Неоднородность банков (на старте и при входе): размер (доли топ-20 из ВКР / равные / Ципф / лог-нормальное), целевой CAR,
целевая ликвидность, издержки, качество заёмщиков `q_i` (лог-нормальный множитель к PD), терпимость к риску на МБК,
скорости подстройки ставок, аппетит к росту кредитов, привлекательность по вкладам, структурная роль на МБК (заёмщик/кредитор/нейтральный).

## 2. Порядок месяца (`BankingModel._step`)

1. **Погашение позиций.** Депозиты в ЦБ и долг перед ЦБ (договоры на месяц) закрываются по ставкам прошлого месяца; МБК закрывается с процентами.
2. **Ставки.** Для каждого банка и сегмента:
   - кредитная цель: `r^L* = k + s^L_s + prem_{i,s} + mp_L·(trust_i − ½) + a_L·max(p_i, 0) + μ_K·max(CAR^tgt_i + 1 п.п. − CAR_i, 0) + Δ^policy_i`,
     где `prem = min(ψ·12·PD_ema_{i,s}·LGD_s, cap)` — премия за ожидаемые потери, `p_i` — давление на ликвидность;
   - цель по вкладам: `r^D* = max(floor, k − s^D_s − mp_D·(trust_i − ½) + a_D·p_i + θ·stress_i + Δ^policy_i)`;
   - подстройка с лагом: `r_t = r_{t−1} + λ_{i,s}·(r* − r_{t−1})`.
     Для кредитов `λ_{i,corp} = clip(v_i, 0.05, 0.9)`, `λ_{i,retail} = clip(v_i + δ, 0.05, 0.9)`,
     где `v_i` — общая случайная скорость банка до ограничения, а `δ` — `banks.rate_speed_loan_retail_shift`.
     При `δ = 0` скорости совпадают. Сдвиг меняет долю разрыва, устраняемую за месяц. Правило расчёта целевой ставки и скорость подстройки вкладов сохраняются.
   Надёжность: `trust = σ((CAR − CAR_ref)/scale + w·ln(A_i/A_med) − 1.5·stress_i)`. Это исправляет механизм «рыночной силы» ВКР, где надёжность `cash/2e6` почти всегда была > 1.
3. **Проценты** (в деньгах): по кредитам — `y = (1−φ)·r^vint + φ·r` (φ — доля плавающих ставок), по вкладам — аналогично, по бумагам — `k − spread`.
4. **Кредитный риск.** Доля дефолтов `d_{i,s} = PD_s·q_i·min(exp(η_s·(y_{i,s} − y^ref_s)), M)·(1 + stress_t)·ε`; потери `LGD_s·d·L` уменьшают капитал, возмещение `(1−LGD)·d·L` возвращается деньгами; амортизация `(L − дефолты)/срок_s`. Редкие крупные идиосинкратические убытки (`idio_event_prob`) — списание без возмещения.
5. **Переоценка бумаг:** `ΔK = −mtm_share·duration·Δy_sec·sec`.
6. **Новые кредиты.** Желаемый запас: `L*_{s,t} = I_t·exp(x_t)`, `x_t = x_{t−1} + κ_L·(x* − x_{t−1})`, `x* = −ε_s·(r̄^L_s − r^ref_s) + шок_спроса + шум`
   (тренд роста `I_t` — номинальный; `ε_s` — эластичность спроса к ставке). Валовая выдача = `max(0, L* − L_после_списаний)`; распределяется между банками логитом
   `∝ (L_i + floor)^ζ · exp(−κ·100·(r_i − r̄)) · appetite_i`. **Ограничение по капиталу:** `ΔRWA_i ≤ K_i/CAR^tgt_i − RWA_i`; нераспределённый спрос
   один раз перераспределяется на банки со свободным капиталом. Банк с дефицитом ликвидности урезает выдачу.
7. **Вклады.** Бегство: `ψ_{i,s} = run_base + (run_stress·stress_i + run_panic·panic·(1.3 − trust_i))·(1 − δ·insured_s)`; часть снятого `leak + leak_panic·panic`
   уходит за пределы сектора. Доля `mobility` вкладов меняет банк. Желаемый запас: `x* = β_s·(r̄^D_s − r^ref_s) + ν·(ln L^sys − ln тренд) + шок + шум` (ν — «кредит создаёт вклады»).
   Приток/отток распределяется логитом `∝ (D_i + floor)^ζ · exp(κ_r·100·(r_i − r̄)) · exp(κ_q·(1 + flight·panic)·(trust_i − ½)) · appeal_i` (бегство в качество).
8. **Резервы, издержки, налоги, дивиденды.** `res = ρ·D`; издержки `c_i·A_i/12`; налог на прибыль; дивиденды платятся, если `CAR ≥ CAR^tgt`.
9. **Ликвидность.** Цель `liq_tgt_i = λ_i·D_i·(1 + panic_liq·panic)`, минимум `floor_share·liq_tgt`.
   - **МБК** (`interbank.py`): заёмщики в случайном порядке; кредитор принимает заёмщика с вероятностью `σ((trust_b − порог_i)/0.08)`; порог растёт при стрессе и панике
     («накопление ликвидности»); выбор кредитора случаен с весом прошлых связей; лимиты: свободная ликвидность, лимит МБК в капитале, лимит на контрагента;
     ставка `k + base + risk·(1 − trust_b)`, заёмщик идёт к ЦБ, если она выше ставки рефинансирования;
   - **ЦБ**: рефинансирование под залог `(1 − haircut)·pledgeable·(L + sec)`;
   - **продажа бумаг** — последняя мера;
   - **избыток**: докупаются бумаги до целевой доли, остаток — депозит в ЦБ (профицит ликвидности).
10. **Платёжеспособность и выход.** Отзыв лицензии, если `K ≤ 0` (или `CAR < revocation_car`) либо ликвидность отрицательна после всех источников.
    Банки с долей активов ≥ `tbtf_threshold` докапитализируются ЦБ. При ликвидации: оценка массы `V = liq + res + депозит ЦБ + (1 − h)·sec + Σ recovery_s·L_s + требования по МБК`;
    первым погашается ЦБ; остальным кредиторам (вкладчики, МБК) — доля `ρ = min(1, остаток/обязательства)`; застрахованные вклады выплачиваются полностью
    (потери АСВ `= застрахованные·(1 − ρ)`); потери кредиторов-банков уменьшают их капитал → **каскад заражения** (повтор проверки до устойчивости);
    выплаченные вклады (за вычетом утечки) возвращаются в систему в следующем месяце. Новый небольшой банк входит на место выбывшего через `entry_delay_months`.
11. **Состояния.** `stress_i` — сглаженное отставание CAR от цели и обращения к ЦБ; паника `panic_t = max(внешний импульс, endo)`,
    `endo_t = decay·endo_{t−1} + sens·max(0, Δk − порог) + contagion·доля_активов_выбывших_банков`.

**Тождество.** После каждого шага для каждого действующего банка `активы − обязательства = капитал` (проверяется при `check_identities=True`
и в тестах). Все потоки меняют обе стороны баланса и капитал.

**Расширение предложения кредита (по умолчанию выключено).** (а) `demand.backlog_exit = θ`: после выдачи тренд спроса сегмента умножается на
`1 − θ·u`, где `u` — доля неудовлетворённого желаемого запаса (спрос уходит с рынка, а не копится). (б) `Scenario.rw_retail_mult`: вес риска розницы
в месяце `t` равен `rw_retail · m_t` (надбавки ЦБ); влияет на CAR и ограничение `ΔRWA ≤ K/CAR^tgt − RWA`. См. `docs/CAPITAL_DIAGNOSTIC.md`.

## 3. Выходные данные

`SimulationResult`:
- `sector` — месячная таблица (по индексу `PeriodIndex`): ставки (ключевая, кредитные/вкладные по сегментам, МБК), объёмы и темпы роста (м/м, г/г),
  долг перед ЦБ, депозиты в ЦБ, профицит ликвидности (`liquidity_surplus`; в обозначениях ЦБ — `structural_liquidity` = −профицит), МБК (объём, ставка, число связей),
  число банков, отзывы лицензий, каскады, расходы АСВ/ЦБ, капитал, CAR (сектора и слабейшего банка), доля новых дефолтов, потери, прибыль, ROE, концентрация (HHI, топ-1/5),
  стресс, паника, отток вкладов, статьи прибыли;
- `banks` — панель «банк × месяц» (активы, кредиты, вклады, капитал, CAR, ликвидность, МБК, долг ЦБ, ставки, надёжность, стресс…);
- `events` — таблица выбытий (месяц, банк, причина: капитал / ликвидность / заражение, активы, потери);
- `network` — ребра МБК по месяцам (при `record_network=True`);
- `scenario` — фактический сценарий (с учётом вмешательств), `config`, `seed`, `meta`.

## 4. Воспроизводимость

Один `SeedSequence(seed)` порождает независимые потоки для инициализации, сценария, спроса, рисков, МБК и входа банков. Одинаковые конфиг и зерно
дают идентичные таблицы (тест `test_determinism_same_seed_identical`); параллельный запуск даёт ту же таблицу, что последовательный.

## 5. Допущения и ограничения

- Клиенты агрегированы: нет домохозяйств и фирм как отдельных агентов; сегментов два.
- Нет валюты, бюджета, реального сектора; ВВП и инфляция входят только через тренды роста и сценарные шоки.
- Срок МБК и рефинансирования ЦБ — один месяц (позиции перезаключаются ежемесячно); льготные программы ЦБ не моделируются.
- Вход нового банка создаёт его вклады и кредиты «из ничего» (малой доли сектора), вложенный капитал фиксируется в `entry_capital`.
- Данные ЦБ о ставках начинаются с 2014 г.: окно калибровки A использует только объёмы (темпы роста); ряды объёмов в данных включают валютную переоценку,
  которой в модели нет, поэтому разброс и автокорреляция месячного роста по умолчанию не входят в цель калибровки.
- Параметры по умолчанию **иллюстративные**; предварительная калибровка (`abm_banks/data/calibrated_window_*.json`) получена с малым бюджетом.

## 6. Что исправлено относительно кода ВКР (`legacy/`)

| Было | Стало |
|---|---|
| `if (flow_type == 'deposit' or 'credit')` всегда истинно | потоки заменены агрегированным спросом и балансами; типов потоков нет |
| `reliability = cash/2e6` → спред почти всегда 3 % | надёжность от капитала, размера и стресса; рыночная сила непрерывна |
| спред 3 % в коде и 4 % в тексте | спреды — параметры конфига |
| `risk_tolerance ∼ U(0, 0.1)` против `prob ∼ U(0, 0.3)` | выдача кредитов ограничена капиталом (CAR), а не случайной «рисковостью» |
| глобальный `settings`, фиксируется при импорте | конфиг-объект передаётся в модель; сценарии меняются между прогонами |
| `random` и глобальный `np.random`, нет зёрен | `Generator` на прогон, зёрна, `run_many` |
| шаг — день, ставка постоянна, нет баланса/капитала/дефолтов | месячный шаг, путь ставки, баланс, капитал, дефолты, выход и вход банков |
