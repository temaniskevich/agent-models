# Агентная модель банковского сектора России

Месячная агентная модель банковского сектора как **генератор синтетических данных** для прогнозирования в кризисных периодах:
неоднородные банки с полными балансами и капиталом, рынок МБК, Банк России, спрос клиентов, дефолты, бегство вкладов,
выбытие и вход банков. Векторизована (100 прогонов по 200 месяцев — секунды), полностью воспроизводима по зерну,
имеет интерактивный интерфейс с графиками «на лету».

Главный вопрос исследования: *улучшают ли синтетические истории из агентной модели прогноз банковского сектора в кризисы, которых мало в данных?*
Подробности — в [CLAUDE.md](CLAUDE.md), формулы и порядок месяца — в [docs/MODEL.md](docs/MODEL.md).

## Установка и запуск

```bash
python -m venv venv && source venv/bin/activate
python -m pip install -r requirements.txt           # для разработки: requirements-dev.txt
streamlit run app.py                                # интерфейс
python -m pytest                                    # тесты
```

## Интерфейс

Вкладки: **Симуляция** (графики строятся по ходу расчёта; кнопки Пуск / Пауза / Шаг / Сброс; скорость; шоки *в ходе* симуляции —
ключевая ставка ±1/3/5 п.п., паника вкладчиков, рост дефолтов), **Банки и сеть** (состояние каждого банка, сеть МБК, тепловая карта CAR по времени),
**Ансамбль** (десятки–сотни прогонов, веерные графики), **Интерпретация** (текстовые выводы, критерии качественного соответствия, проверки по российским работам),
**Калибровка** (по данным ЦБ, окна A и B, проверка вне выборки), **Синтетика** (генератор набора историй + контроль без экономики, выгрузка в Parquet/CSV), **О модели**.
В боковой панели — пресеты и ~100 параметров по группам; конфиг можно скачать и загрузить (JSON/YAML).

## Использование из Python

```python
from abm_banks import BankingModel, ModelConfig, preset
from abm_banks.batch import run_many, generate_synthetic

cfg = preset("rate_shock_panic").replace(**{"banks.car_min": 0.09, "n_months": 120})
res = BankingModel(cfg, seed=1).run()
res.sector[["key_rate", "loan_rate", "deposit_rate", "loans_growth_yoy", "cb_debt", "n_banks"]].head()
res.banks, res.events                      # панель банков, таблица выбытий

runs = run_many(cfg, seeds=200, n_jobs=8)  # длинная таблица прогонов
data, meta = generate_synthetic(cfg, n_runs=2000, outdir="outputs/synthetic_v1", n_jobs=8)
```

Те же операции из командной строки: `scripts/generate_synthetic.py`, `scripts/calibrate.py`, `scripts/fetch_cbr_data.py`.

## Данные

`abm_banks/data/cbr_monthly.csv` — месячные ряды Банка России (кредиты и вклады, ставки по новым кредитам и вкладам, ключевая ставка,
ликвидность банковского сектора), собранные скриптом `python -I scripts/fetch_cbr_data.py` с cbr.ru. Для июня 2010 – августа 2013
ключевая ставка заменена ставкой рефинансирования, внесённой вручную (колонка `key_rate_source`) — сверьте с cbr.ru.
